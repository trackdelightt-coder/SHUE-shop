# MSTAR 家具商店

給玩家瀏覽、下單 MSTAR 遊戲家具的網站。包含：

1. **買家頁面**（`index.html`）：瀏覽家具、加入購物車、自動計算總金額、送出訂單
2. **後台管理**（`admin.html`）：密碼登入後可新增/編輯/刪除/上下架商品、查看所有訂單並更新訂單狀態、編輯商店公告
3. **下單自動通知 Discord**：買家送出訂單後，系統會自動計算金額並發訊息到你指定的 Discord 頻道
4. **商品分類（可加 emoji）**：分類名稱可以直接輸入 emoji，例如「🛋️ 客廳」，買家頁面的分類選單就會顯示 emoji
5. **商店公告區**：買家頁面最上方會顯示公告（例如營業時間、交易比例、注意事項），可在後台「商店設定」分頁隨時編輯
6. **糖果／現金 雙軌計價**：每件商品同時設定「🍬 糖果價」與「💵 現金價（NT$）」兩組價格。買家在購物車面板選擇「本次訂單付款方式」（糖果或現金），**同一筆訂單只能用一種付款方式**，不能一部分用糖果、一部分用現金；如果購物車裡已經有商品時切換付款方式，系統會提醒並清空購物車重新選購

## 一、如何在自己的電腦試跑（本機測試）

需要先安裝 [Node.js](https://nodejs.org/)（建議 18 版以上）。

```bash
# 1. 進入專案資料夾
cd mstar-furniture-shop

# 2. 安裝套件
npm install

# 3. 複製設定檔並填入你的密碼/Discord網址
cp .env.example .env
# 用文字編輯器打開 .env，修改 ADMIN_PASSWORD 和 DISCORD_WEBHOOK_URL

# 4. 啟動網站
npm start
```

啟動後：
- 買家頁面：http://localhost:3000
- 後台管理：http://localhost:3000/admin.html（密碼是 .env 裡設定的 ADMIN_PASSWORD）

## 二、如何設定 Discord 下單通知（Webhook）

Discord Webhook 是「一個網址」，程式只要對這個網址發送資料，訊息就會自動出現在你指定的頻道，不需要另外做機器人帳號。

設定步驟：
1. 打開 Discord，進入你想接收訂單通知的伺服器
2. 選擇要接收通知的頻道 → 點頻道旁的齒輪（編輯頻道）
3. 左側選單點「整合 (Integrations)」→「Webhook」→「建立 Webhook (New Webhook)」
4. 可以幫這個 Webhook 命名，例如「MSTAR訂單通知」
5. 點「複製 Webhook URL (Copy Webhook URL)」
6. 打開專案裡的 `.env` 檔案，貼到這一行：
   ```
   DISCORD_WEBHOOK_URL=你複製的網址
   ```
7. 重新啟動網站（`npm start`），之後每次有人下單，該頻道就會自動收到訂單通知（含買家、商品明細、總金額）

> 如果先不設定，網站仍可以正常下單，只是不會發 Discord 通知（後台console會顯示「尚未設定」）。

## 三、如何正式上線給玩家使用

目前這個版本可以在你自己的電腦上執行，但只有你自己能連線。如果要讓所有玩家都能連進來下單，需要把它「部署」到一台隨時開機、有固定網址的主機上。常見免費/低價選項（適合小商店規模）：

- **Render** (render.com)：把專案上傳到 GitHub，Render 可以自動幫你部署成一個網址，有免費方案
- **Railway** (railway.app)：操作簡單，適合新手，有免費額度
- **Zeabur**（台灣團隊做的，中文介面友善）：zeabur.com

部署方式大致都是：
1. 把這個資料夾放到 GitHub（或直接上傳）
2. 在該平台建立新專案，指向這個資料夾
3. 設定啟動指令為 `npm install && npm start`
4. 在該平台的「環境變數 (Environment Variables)」設定裡填入 `ADMIN_PASSWORD` 和 `DISCORD_WEBHOOK_URL`
5. 平台會給你一個網址，例如 `https://mstar-shop.onrender.com`，之後玩家用這個網址就能下單

如果你想要我直接幫你部署到某個平台，告訴我你想用哪一個（或是否已經有主機），我可以再幫你走完整流程。

## 四、資料存放方式（目前版本）

- 商品資料存在 `data/items.json`
- 訂單資料存在 `data/orders.json`
- 這是最簡單的檔案式資料庫，適合商品數量不多、訂單量不大的情況。未來如果訂單量變大，建議升級成正式資料庫（例如 SQLite 或雲端資料庫），我可以之後幫你升級。
